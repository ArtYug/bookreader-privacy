# Lexirion — публичная страница

Здесь лежит только политика конфиденциальности приложения Lexirion для Android.
Исходный код приложения в этот репозиторий не входит.

Репозиторий публичный по одной причине: Google Play требует, чтобы ссылка на политику
конфиденциальности открывалась у кого угодно и без входа в аккаунт, а GitHub Pages на
бесплатном тарифе публикует сайты только из публичных репозиториев.

## Адреса

- Политика: https://artyug.github.io/bookreader-privacy/privacy-policy.html
- Страница приложения: https://artyug.github.io/bookreader-privacy/

Первый из них указан в карточке Google Play и открывается из самого приложения
(Настройки → About → Privacy policy).

## Как обновлять

Правится `privacy-policy.html`, коммит, push — Pages пересобирает страницу сама, за минуту.
Дату вверху файла надо менять вместе с текстом: она там не для красоты, на неё смотрят и
пользователь, и проверяющий Play.

Приложение при этом ничего не знает о содержимом страницы — только её адрес, зашитый в
`privacy_policy_url`. То есть текст можно править, не выпуская новую версию приложения.

## Настройка Pages (делается один раз)

Settings → Pages → Source: Deploy from a branch → Branch: `main`, папка `/ (root)`.
